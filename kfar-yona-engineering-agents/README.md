# סוכני Claude Code — אגף ההנדסה, עיריית כפר יונה

חבילת סוכנים (subagents) של Claude Code המדמה את המבנה הארגוני של אגף ההנדסה
בעיריית כפר יונה: סוכן-על אחד ו-18 סוכנים מומחים (כולל ארבעה סוכני-בן
מתמחים), הנשענים כולם על בסיס ידע משותף וקבוע.

> **מעמד הפרויקט:** זוהי חבילה **נפרדת ועצמאית**, ניתנת לגרסאות ב-git, המשקפת
> ומתעדת את אותו מבנה ארגוני כמו חבילת Skills חיה (`hub-handasa-kfar-yona`
> ועוד כ-20 סקילים) הפועלת בפועל בסביבת Claude של בעל התיק. החבילה כאן **אינה**
> מסונכרנת אוטומטית עם הסקילים החיים, ואין בה מנועי חישוב/קריאת קבצים בפועל
> (למשל מנוע תמחור לפי מחירון דקל, קריאת DWG) — היא שכבת תיעוד ארכיטקטוני
> ניידת לשימוש מחוץ לסביבת ה-Skills (שיתוף, גיבוי, פרויקטי Claude Code אחרים).

## התקנה / שימוש

**אופציה א' — פרויקט ייעודי (מומלץ):** פתחו את תיקיית `kfar-yona-engineering-agents`
כפרויקט Claude Code בפני עצמו (יש בה כבר `.claude/agents` ו-`.claude/knowledge`).
הסוכנים ובסיס הידע ייטענו אוטומטית.

**אופציה ב' — שילוב בפרויקט קיים:** העתיקו את `.claude/agents/*.md` ואת
`.claude/knowledge/kfar-yona-baseline.md` לתוך `.claude/agents/` ו-`.claude/knowledge/`
של הפרויקט שלכם.

**אופציה ג' — זמינות גלובלית בכל הפרויקטים:** העתיקו את קובצי `.claude/agents/*.md`
אל `~/.claude/agents/`, ואת `kfar-yona-baseline.md` למיקום קבוע וציינו את הנתיב
המלא בראש כל קובץ סוכן (כברירת מחדל הקבצים מפנים לנתיב היחסי
`.claude/knowledge/kfar-yona-baseline.md`).

לאחר ההתקנה, ניתן לפנות ישירות לסוכן-העל ("תשאלו את סוכן-העל של אגף ההנדסה על...")
או ל-Claude Code לתת לו לבחור אוטומטית את הסוכן המתאים לפי תיאור הפנייה.

## חשוב — לפני שימוש בפועל

בסיס הידע (`kfar-yona-baseline.md`) כולל אך ורק את העובדות שנמסרו/אומתו
במפורש (מעמד עירייה משנת 2014, מדד סוציו-אקונומי 7/10, סדר גודל אוכלוסייה,
קיום אתר עירייה/אתר הנדסי בקומפלוט/מערכת GIS, ועדת תנועה ונגישות, הנחיות
מרחביות, היתרי חפירה, רישוי, תיאום תחבורה ציבורית). כל שדה המסומן `[להשלמה]`
— קישורים, טלפונים, שמות ועדות מדויקים — **טרם אומת** ויש להשלימו בנתונים
רשמיים לפני הפצה או הסתמכות מבצעית. הסוכנים מתוכננים באופן מכוון שלא להמציא
עובדות, קישורים או פרטי קשר שאינם מתועדים.

## עקרון העבודה

1. **סוכן-העל (`handasa-chief`)** הוא שער הכניסה: הוא מסווג את הפנייה, מפנה
   לסוכנים המומחים הרלוונטיים, ומסנתז תשובה אחודה לפניות רב-תחומיות.
2. **ארבעה סוכני-בן מתמחים** (`handasa-permit-deep-check`,
   `handasa-infra-coordination-check`, `handasa-cost-engine`) מבצעים בדיקה/
   חישוב מעמיק בתוך תחום סוכן-האם שלהם, ומפיקים דוח/פלט בפורמט קבוע — להבדיל
   מסוכן-האם שעונה על שאלות הליך/ניהול כלליות.
3. **כל סוכן** מוגדר עם תחום אחריות ברור, גבולות מפורשים ("מתי להפנות לסוכן
   אחר"), ועקרונות מענה המבטיחים שהוא לא ימציא נתונים רגולטוריים/כספיים/כתובות.
4. **`handasa-grants`** (קולות קוראים ותמיכות) מתוכנן להשתלב עם סקיל/כלי קולות
   קוראים קיים בפרויקט אם קיים כזה, ולא לשכפל אותו.

## התאמה אישית

כדי להתאים את החבילה למציאות המדויקת באגף:

- מלאו את כל השדות המסומנים `[להשלמה]` בקובץ `kfar-yona-baseline.md`.
- הוסיפו סעיף "מקורות מידע רשמיים" עם קישורים מאומתים (אתר העירייה, קומפלוט, GIS).
- במידת הצורך, פצלו/מזגו סוכנים בהתאם למבנה הארגוני בפועל של האגף.
