# הקשר פרויקט — סוכני אגף ההנדסה, כפר יונה

פרויקט זה מכיל הגדרות סוכנים (subagents) של Claude Code המדמות את המבנה הארגוני
של אגף ההנדסה בעיריית כפר יונה. ראו `README.md` למפת הסוכנים והוראות התקנה, ואת
`.claude/knowledge/kfar-yona-baseline.md` לבסיס הידע המשותף.

## כללי ברזל לכל עבודה בפרויקט זה

1. **אל תמציאו עובדות.** כל פרט שאינו מתועד ב-`kfar-yona-baseline.md` ואינו ידוע
   בוודאות מלאה — יש לסמנו כטעון אימות מול הגורם הרשמי באגף ההנדסה, ולא להציגו
   כעובדה.
2. **אל תמציאו קישורים, טלפונים או פרטי קשר.** קישור לאתר העירייה, לקומפלוט, ל-GIS,
   או לכל מערכת אחרת יינתן רק אם הוא מתועד במפורש בבסיס הידע או אותר בפועל בכלי
   חיפוש/דפדוף באותה שיחה.
3. **חקיקה ותקינה מתעדכנות.** כל אזכור של חוק התכנון והבנייה, תקנות, או תקנים
   ישראליים (כגון ת"י 1918) ילווה בהמלצה לאימות מול הפרסום הרשמי העדכני.
4. **הפניה בין סוכנים.** פנייה רב-תחומית תטופל דרך `handasa-chief`, שיפנה לסוכנים
   המומחים הרלוונטיים ויסנתז תשובה אחודה — סוכן בודד לא ינסה לענות מחוץ לתחומו.
